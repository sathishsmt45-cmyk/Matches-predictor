# Matches-predictor

Live last-digit stats and a Matches prediction tracker for volatility-index ticks, connected in the browser to the Deriv public WebSocket. Served at https://sathishsmt45-cmyk.github.io/matches-predictor/.

The page now supports Matches, Differs, Even, Odd, Over, Under, Rise, Fall, Higher and Lower, plus a DBot XML upload.

The page now has a Prediction digit card with auto-trade on the predicted digit (demo/educational only, no edge).
